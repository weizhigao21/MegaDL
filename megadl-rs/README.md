# MegaDL（Rust 重构版）

对 `mega_proto`（Python 原型）的 Rust 重构，协议实现与 MegaDownloader 1.8 的
静态逆向结论逐字段对齐。桌面界面使用 egui，无 WebView、无额外运行时依赖。

当前版本 **v0.1.4**：界面标题与状态栏显示版本号，Windows 文件属性里的
文件/产品版本同为 0.1.4.0（由 `build.rs` 写入）。解析链接时会校验密钥长度
（文件链接 43 个字符、文件夹链接 22 个字符），被截断的链接会直接提示
“密钥不完整”。下载改为边收边解密落盘（每 256KB 刷新进度），连接被重置后
以百毫秒级短退避换线路重试；实时速度用约 2 秒指数平滑，右侧数字与单位分字号
显示，窄卡片不会折行。

## 构建与运行

```powershell
cd "E:\code\MegaDownloader-逆向\megadl-rs"
cargo build --release
.\target\release\megadl.exe            # 图形界面
```

无界面模式（脚本 / 验证用）：

```powershell
.\target\release\megadl.exe --list "https://mega.nz/folder/<id>#<key>"
.\target\release\megadl.exe --get  "https://mega.nz/file/<id>#<key>" --out D:\Downloads -j 8
.\target\release\megadl.exe --get  "<链接>" --eu          # EU 线路优先
.\target\release\megadl.exe --get  "<链接>" --proxy http://127.0.0.1:7890
.\target\release\megadl.exe --demo                        # 界面演示数据（不联网）
```

## 界面

默认窗口 1200 × 820，浅灰底 + 白色圆角卡片，左右分栏：

启动时窗口自动居中；程序使用 Windows GUI 子系统，双击不会再闪出控制台窗口，`--list` / `--get` 会附着到当前终端输出。

- 顶栏：应用标识、名称，右侧「日志 / 设置」
- 链接卡片：输入 / 粘贴 / 解析，支持文件、文件夹及旧版 `#!` / `#F!`
- 左侧文件卡片：自绘文件树（34px 行高、勾选框随层级缩进并紧贴图标、文件夹展开箭头与类型图标），文件夹可展开/折叠并支持「展开全部 / 收起全部」，勾选文件夹会级联到其下全部文件，三态显示全选/部分/未选；行悬停有底色，文件行双击直接下载
- 右侧「本次下载」：已选文件数、总大小、实时速度、总进度；下载选中 / 全部下载 / 停止
- 右侧「当前选择」：文件名、大小、状态、相对路径、复制直链
- 右侧「环境」：API 线路、并发配置、保存位置、打开下载目录
- 底部状态栏：当前状态与运行参数

下载目录会按树中的相对路径自动创建子目录；文件夹行只做选择与展开，不提供单独直链。

设置（自动保存到 `%APPDATA%\megadl\config.json`）：

| 项 | 说明 |
| --- | --- |
| 保存目录 | 默认系统下载目录，可浏览选择 |
| 并发连接数 | 1–16，单文件内部的分块并发（默认 8） |
| 同时下载文件数 | 1–6，多个文件并行下载（默认 3） |
| 分块大小 | 1–16 MB，16 字节对齐（默认 4） |
| API 线路 | 自动（G 优先，连接失败切 EU）/ EU 优先 |
| 代理 | 如 `http://127.0.0.1:7890`，留空直连；支持 HTTP/SOCKS |
| 重名文件 | 自动重命名 / 覆盖 / 跳过 |
| 外观 | 浅色 / 深色 / 跟随系统 |

## 速度调优

默认值已按“单文件 8 连接 × 同时 3 个文件、4MB 分块”配置，适合多数公共分享：

- 单个大文件慢：把「并发连接数」提高到 12–16；MEGA 对单连接常有速率上限，多连接才能叠加。
- 文件夹里很多文件慢：提高「同时下载文件数」，总吞吐按文件并行叠加。
- 总连接数（连接数 × 文件数）不建议超过 32，过高可能触发 MEGA 的连接/配额限制。
- 国内直连慢：在设置里填本地代理（如 Clash 的 `http://127.0.0.1:7890`），或把线路切到 EU 试试。
- **先确认不是配额问题**：MEGA 对未登录/免费用户按 IP 统计最近 6 小时的下载量
  （常见额度约 1–5GB，随地区和负载浮动）。额度接近用尽时会明显降速，用尽后
  直接返回 `EOVERQUOTA / 509`，这不是客户端能绕过的，只能等 6 小时窗口滚动重置、
  换网络出口或升级账号。状态栏会显示实时速度，日志会记录具体错误。

## 代码结构

| 文件 | 职责 | 对应 Python 原型 |
| --- | --- | --- |
| `src/mega.rs` | 链接解析、AES-CBC 属性解密、ECB 节点密钥、CTR 偏移解密、G/EU API | `mega.py` 的协议部分 |
| `src/download.rs` | 多线程 Range 分块、`.part` 预占位、重试、取消、重名策略 | `Downloader` |
| `src/config.rs` | 设置 JSON 持久化 | 原型无（新增） |
| `src/app.rs` | egui 界面、事件循环、进度/速度统计 | `mega_gui.py` |
| `src/main.rs` | GUI 入口 + `--list` / `--get` 无界面模式 | `mega.py` CLI |
| `build.rs` | Windows 下把 `assets/megadl.ico` 嵌入 exe（需 SDK 的 rc.exe） | 原型无 |
| `assets/megadl.ico` | 程序图标（蓝底 M + 下载箭头，含 16–256 多尺寸） | 原型无 |
| `tests/e2e.rs` | 本地假 MEGA 服务端到端测试 | `test_local.py` |

加密实现只依赖 `aes` crate，CBC / CTR / ECB 模式按逆向结论手写（IV 全 0、
计数器大端进位、密钥前后 16 字节异或），与 `SicSeekableBlockCipher` 行为一致。

## 测试

```powershell
cargo test          # 8 个单元测试 + 2 个端到端测试
```

- 单元测试与 `mega_proto/selftest.py` 同源：链接解析、属性解密、CTR 任意偏移、节点密钥、文件名清洗
- 文件树测试：嵌套路径生成、文件夹大小递归汇总、根节点判定
- 端到端与 `test_local.py` 同源：3,146,962 字节、4 连接分块下载逐字节一致；另覆盖重名策略与取消

## 已知边界

- 文件夹解析只取公共分享可见的节点；节点属性解密失败的条目会被跳过
- 不做登录 / 会话、MegaCrypter 等第三方加密链接、meta-MAC 校验
- 停止后 `.part` 保留，但不做断点续传（重新下载会重新分块）
- 本机到 MEGA API 的链路偶发整段失败（Python 原型同样如此，实测约 5/6 成功），
  已做 G/EU 互换 + 递增退避重试；失败时再点一次解析即可

逆向依据见上一级目录 `逆向分析笔记.md` 与 `逆向产物/`。
